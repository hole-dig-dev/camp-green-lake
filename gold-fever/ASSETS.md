# Material sources — version 0.15

All downloaded material images are from Poly Haven's official API/CDN over HTTPS with normal TLS certificate validation. Their [asset license](https://polyhaven.com/license) is CC0-1.0, allowing redistribution and commercial use. Images are shipped locally; players do not contact an asset website at runtime. No installer, executable, plugin or external JavaScript was downloaded for this release.

| Surface | Original asset | Included maps |
| --- | --- | --- |
| Dirt/gravel | [Aerial Ground Rock](https://polyhaven.com/a/aerial_ground_rock) | Color, displacement used as bump, roughness |
| Canyon/mine/rocks | [Sandstone Cracks](https://polyhaven.com/a/sandstone_cracks) | Color, displacement used as bump, roughness |
| Sawn wood | [Wood Planks](https://polyhaven.com/a/wood_planks) | Color, OpenGL normal, roughness |
| Iron and machinery | [Rusty Metal 02](https://polyhaven.com/a/rusty_metal_02) | Color, OpenGL normal, roughness |

Twelve 1024px JPEGs total 5,040,509 bytes. Every download passed JPEG signature, exact published byte-size and published MD5 checks. The manifest records its exact HTTPS URL and SHA-256 for later integrity checks. Those checks establish source/file consistency, not an antivirus clearance. A Microsoft Defender custom folder scan was attempted on this machine but Windows denied access.

The grass-covered Rocky Terrain 02 candidate was rejected after visual inspection and replaced with sandstone. Only the final twelve maps are included. Bark, cut-log rings and cloth weave are generated by local code in public/materials.mjs. Existing meshes, UI and other visuals are game-generated.

## Original models - 0.16

Miners and heavy vehicles are generated by local source in miner-model.mjs, vehicle-model.mjs and model-parts.mjs. No external models, reference images or new asset downloads are shipped for this art pass. Existing CC0 texture provenance remains above.

Colors are muted and normalized in the shader to keep the warm cartoon palette. The scan's height is used for small lighting relief, not physics displacement. Dirt/rock are projected in world metres; the current dirt tile is about 3.33m and sandstone tile about 4.17m. These scales and source images can be carried into an Unreal material using world-aligned projection, with metres converted to centimetres.

## Western scenery and light - 0.17

[Quaternius Stylized Nature MegaKit](https://quaternius.com/packs/stylizednaturemegakit.html), Standard free release, downloaded from the publisher's [itch.io page](https://quaternius.itch.io/stylized-nature-megakit). Included models: Pine_1, Pine_3, Pine_5, Bush_Common, Grass_Common_Short, Rock_Medium_1 and their referenced buffers/images. CC0 1.0 is confirmed in assets/nature/License.txt. Only glTF/mesh buffers/PNG images/license text were extracted from the archive; no executable, installer, engine project or Blender file is shipped. Archive and per-file SHA-256/source records are in assets/nature/manifest.json. Google Drive's older pack download returned quota exceeded; no bypass was used.

[Poly Haven Sunflowers PureSky](https://polyhaven.com/a/sunflowers_puresky), CC0, 1K HDR, 1,482,923 bytes. Normal HTTPS/TLS download, exact published size and MD5 checked; SHA-256 recorded in assets/nature/sky-manifest.json. Three.js GLTFLoader, HDRLoader and BufferGeometryUtils are vendored from the already installed official Three.js dependency, with only the browser import path adjusted. MIT license is included in public/vendor/THREE-LICENSE.txt. All runtime asset requests are local.

## Camp Green Lake camper - JT 2026-10-05

`public/assets/characters/camper.glb` is Camp Green Lake's own Blender camper (camp-green-lake `public/models/camper.glb`,
original work for JT's games): a rigid-segment rig with 12 bones, 13 clips (Idle, Walk, Run, Dig, KO, Wave, ...), the camp
shovel and three hats. `public/camper-model.mjs` uses it for players and the town NPCs, and its shovel in first person.
`public/vendor/utils/SkeletonUtils.js` is vendored from the installed official Three.js dependency (MIT, see
`public/vendor/THREE-LICENSE.txt`) with only the import path adjusted, like the other vendored files.
